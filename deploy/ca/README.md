# 추가 루트 인증서(선택)

회사 보안 장비가 HTTPS 연결을 중간에서 다시 서명하는 망(예: 사내 보안 게이트웨이)에서 빌드·실행할 때만 씁니다.

- 그 장비의 **루트 인증서**를 PEM 형식(`*.pem`)으로 이 폴더에 넣고 이미지를 빌드합니다.
- 빌드 때는 npm 패키지 내려받기에, 실행 때는 외부 AI 서비스(Soniox·OpenAI·Cartesia) 접속에 쓰입니다.
- 인증서 검증을 끄는 것이 아니라, 회사가 이미 신뢰하는 인증서를 Node 에도 알려 주는 것입니다.
- `*.pem` 파일은 git 에 올라가지 않습니다(`.gitignore`).
