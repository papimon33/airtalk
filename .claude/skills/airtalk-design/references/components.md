# AirTalk 부품 규격

값은 AirTalk 실제 코드에서 옮겼다. 색 이름은 `tokens.css` 변수(`--at-*`) / MUI 테마 이름(`BRAND`, `BAR_BG`, `SOFT_BG`, `HOVER`).
단위: px. MUI `sx` 간격 1 = 8px.

## 버튼

| 종류 | 크기 | 모서리 | 바탕 / 글자 | 쓰임 |
|---|---|---|---|---|
| 주 버튼 | 높이 40, 좌우 16, 14/700 | 12 | 브랜드 / 흰색 | 저장·만들기 (화면에 하나) |
| 큰 주 버튼 | 높이 48–56, 15.5/700–800 | 14–16 | 브랜드 / 흰색, 그림자 `--at-shadow-brand` | 시작·만들기(창 아래) |
| 보조 버튼 | 높이 40–52 | 12–16 | `--at-fill` / 본문 | 취소·뒤로 (주 버튼 왼쪽, 폭 약 32%) |
| 위험 버튼 | 주 버튼과 같음 | 같음 | `--at-danger` / 흰색 | 삭제·중지 |
| 아이콘 버튼 | 40×40 (폰 48×48) | 10–12 | 투명, 켜짐이면 `--at-brand-soft` + 브랜드 아이콘 | 위 띠·조작 바 |
| 진행 중 시작 버튼 | 큰 주 버튼 + 빨강 | | `--at-danger` / 흰색, 흰 사각형 아이콘 + "중지" | |

- 주 버튼은 **둥근 네모**(알약 아님). 텍스트는 짧은 동사("만들기", "시작", "저장").
- 확인 창 버튼은 두 칸 같은 폭(높이 50, 모서리 14): [취소(회색)] [확인(브랜드 또는 위험)].

## 위 띠(헤더)

- PC 목록: 높이 60, 왼쪽 워드마크(24px), 오른쪽 **이름 메뉴** = 아바타(30px 원, 브랜드 바탕 흰 이니셜) + 이름 13.5/700 + ⌄. 누르면 메뉴(이름·ID / 설정 / 관리자 / 앱 설치 / 로그아웃(빨강)).
- PC 작업 화면: 높이 56, [← 36px] [제목 16/800] [모드 알약(26px, `--at-fill`, 12.5/700 + ⌄)] [진행 표시 알약: 빨강 12% 바탕, 7px 점 + "번역 중 03:12"(tabular)] … [보조 수 13] [보조 강조 버튼: 옅은 보라 바탕 + 보라 글자 "링크 공유"].
- 폰: 제목 18/800 + 오른쪽 아이콘 버튼 2–3개. 진행 중엔 위·아래가 숨고 화면을 누르면 4초 보인다.

## 조작 바(디스코드식, 화면 아래 가운데)

```
[🎤 ⌄] [≋ ⌄]   [입력 언어 ⌄ → 출력 언어 ⌄]   [⋯]   [▶ 시작]
```
- 묶음(group): 회색 `--at-bar`, 모서리 14, 안쪽 4, 그림자 `--at-shadow-bar`. 묶음 사이 8.
- 아이콘+⌄ 묶음(split): 아이콘 40×40 + ⌄ 22×40(보조 글자색). 음소거 등 위험 상태면 묶음 바탕을 빨강 12%, 아이콘 빨강. 꺼짐은 보조 글자색 + 사선.
- 값 칸(언어 등, 늘 보임): 높이 40, 좌우 10, 위 캡션 10.5/600 보조색 + 값 13.5/700 + ⌄. 열림이면 옅은 보라 바탕. 진행 중엔 잠기고 누르면 안내 토스트.
- 주 행동은 묶음 밖 큰 주 버튼(높이 48).
- 아래 여백 16, 화면이 좁으면 줄바꿈(flex-wrap).

## 작은 메뉴(⌄) — 제목 없음

- 버튼 바로 위에 뜬다. 폭 260–300, 모서리 12, 그림자 `--at-shadow-menu`, 위아래 안쪽 6.
- **줄(Row)**: 좌우 바깥 6 + 안쪽 8, 최소 높이 34, 모서리 8, hover `--at-hover`. 제목 13.5/600 + 아래 지금 값 12 보조색. 고르는 줄이면 오른쪽 ›.
- **옆 목록(SubMenu)**: 줄에 마우스를 올리면(누르면) 오른쪽으로 같은 모양의 메뉴. 항목 = 이름(+작은 부가 이름) + 오른쪽 **동그라미 라디오**(16px, 고르면 브랜드 테두리 + 6px 점). Esc 는 메뉴 전체를 닫는다(옆 목록이 열려 있어도).
- **켜고 끄기**: 오른쪽 네모 체크(18px, 모서리 5, 켜지면 브랜드 바탕 흰 체크).
- **두 칸 선택**: 줄 오른쪽에 회색 알약 안 [꺼짐|켜짐] (높이 26, 고른 칸: 켜짐=브랜드 바탕 흰 글자, 꺼짐=흰 바탕).
- **막대(음량·글자 크기)**: 이름 13.5/600 + 오른쪽 값(%) 12.5/700, 아래 small 슬라이더(브랜드, 손잡이 14).
- 구분선: 위아래 6, 좌우 12 들여서.
- 쓸 수 없는 항목은 숨기지 말고 흐리게(투명도 0.45).

## 설정

- **폰(시트·전체 화면)**: 바탕 `--at-settings-bg`, 섹션 제목 13/700 보조색, 흰 묶음 카드(모서리 18) 안에 줄(최소 높이 54, 제목 16/700, 오른쪽 값 14.5 보조색 + ›, 줄 사이 구분선은 왼쪽 18 들여서). 고르면 아래 시트에서 하나 선택.
- **PC(가운데 창)**: 760×540, 모서리 16. 왼쪽 분류(폭 196, 바탕 `#F5F5F7`/다크 `#26262A`, 항목 높이 36·모서리 8, 고른 항목 옅은 보라 + 보라 글자). 오른쪽: 분류 제목 18/800 + 닫기 ✕, 줄 = 왼쪽 [이름 14/700 + 설명 12.5 보조색] / 오른쪽 [드롭다운(폭 200) · 구간 버튼 · 슬라이더 · 입력+저장]. 줄 사이 구분선.
- **구간 버튼(segmented)**: 회색 알약(모서리 10, 안쪽 4) 안에 높이 32 칸, 고른 칸은 흰 바탕 + 얕은 그림자.

## 대화상자·시트

- 확인 창: 폭 최대 360, 모서리 24, 안쪽 24/20, 제목 가운데 19/800, 설명 가운데 14 보조색, 버튼 두 칸.
- 입력 창(이름 바꾸기 등): 같은 모양 + 입력칸(높이 54, 모서리 16, 바탕 `--at-fill`, 테두리 없음).
- 폰 시트: 아래에서, 위 모서리 28, 손잡이(40×4 알약). PC 에서는 같은 내용을 가운데 창(폭 480)으로.
- 새로 만들기 창: 제목 21/800 → 선택 카드들(모서리 20, 테두리 2, 고르면 브랜드 테두리 + 옅은 보라 바탕, 왼쪽 44px 아이콘 칸) → 값 칸 2열(높이 66, 모서리 16) → 이름 입력 → [취소][만들기].

## 목록

- 줄: 왼쪽 40px 아이콘 칸(모서리 12, 종류별 옅은 바탕) + 제목 15/700 + 아래 '시각 · 종류' 12.5 보조색. 줄 사이 선 없음, hover 바탕(모서리 16). PC 는 hover 때 오른쪽 ⋮.
- 위 줄: [검색(모서리 12)] [선택(텍스트 버튼)] [+ 새 항목(주 버튼)].
- 빈 화면: 가운데 제목 17/700 + 한 줄 안내 14 보조색.

## 대화(번역 카드)

- 단방향: 번역문 22/500(행간 1.45) + 아래 원문 14.5 보조색. 진행 중(확정 전)은 보조색.
- 양방향 말풍선: 상대(왼쪽) `--at-accent` 10% 바탕, 모서리 `6 20 20 20` / 나(오른쪽) 본문 6% 바탕, 모서리 `20 6 20 20`. 위에 '한국어 → 일본어' 12/700(방향이 바뀔 때만).
- 글자 크기는 설정값(80–160%)을 곱한다.

## 언어 목록

- 한 줄 = 화면 언어로 부른 이름(굵게) + 아래 작은 영어 이름(예: `한국어 · Korean`, `일본어 · Japanese`). 영어 화면이면 그 언어 자신의 이름(`Japanese · 日本語`).
- 위에 검색칸(높이 34, 모서리 8, `--at-fill`). 지원하는 모든 언어를 보이고, 입력 언어는 맨 위에 '자동 감지'.
