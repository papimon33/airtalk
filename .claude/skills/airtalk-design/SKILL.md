# AirTalk 디자인 시스템

AirTalk 은 공항 현장용 실시간 통역 앱이다. 디자인 성격: **조용한 뉴트럴 바탕 위에 보라 하나만 강조**, 플랫(그림자는 떠 있는 것만), 큰 둥근 모서리, 굵은 한글 제목, 필요한 정보만. 이 스킬은 그 규칙을 다른 앱에 옮기는 법이다.

## 먼저 할 일

1. 대상 프로젝트의 스택을 확인한다.
   - **React + MUI** → `references/mui-theme.js` 를 복사해 `ThemeProvider` 에 넣는다.
   - **그 밖**(HTML·Tailwind·Vue·Svelte 등) → `references/tokens.css` 의 CSS 변수를 쓰고, 다크는 `[data-theme="dark"]`/`prefers-color-scheme` 로 같은 변수를 바꾼다.
2. 글꼴을 넣는다(아래 '글꼴'). 글꼴이 없으면 디자인이 전혀 다르게 보인다.
3. 화면을 만들 땐 `references/components.md` 의 부품 규격을 따른다(값을 새로 지어내지 말 것).
4. 화면 문구는 `references/copy-rules.md` 규칙대로 쓴다.

대상 프로젝트에 이미 디자인 시스템이 있으면, 사용자가 AirTalk 디자인을 원한다고 했을 때만 덮어쓴다. 섞을 때는 색·글꼴·모서리 토큰부터 맞추고 부품은 하나씩 바꾼다.

## 핵심 토큰(요약 — 전체는 references/tokens.css)

| 역할 | 라이트 | 다크 |
|---|---|---|
| 브랜드(주 버튼·켜짐·선택) | `#5B4FE8` (hover `#4A3FD4`) | `#8579FF` (hover `#9A90FF`) |
| 브랜드 옅은 바탕(선택됨·켜짐 칸) | `#EEEDFC` | `rgba(91,79,232,0.28)` |
| 바탕(캔버스) | `#FFFFFF` | `#1F1E1D` |
| 카드·창(paper) | `#FFFFFF` | `#30302E` |
| 설정 화면 바탕(폰) | `#F4F3EF` | `#1F1E1D` |
| 조작 바·묶음 회색 | `#F1F1F4` | `#2B2D31` |
| 본문 글자 | `#1F1E1D` | `#FAF9F5` |
| 보조 글자 | `#6B6A63` | `#B3B1A9` |
| 구분선 | `rgba(31,30,29,0.12)` | `rgba(250,249,245,0.10)` |
| 위험(삭제·중지·음소거) | `#E01E5A` | `#F47C7C` |
| 성공 | `#007A5A` | `#2EB67D` |
| 경고 | `#E8912D` | `#E8A03E` |
| 보조 강조(상대방 말풍선 등) | `#2E6FD8` | `#84B5FF` |

- **보라는 하나만.** 주 행동 1개(시작·만들기·저장), 켜짐/선택 표시, 로고 점에만 쓴다. 나머지는 뉴트럴.
- **모서리**: 버튼·입력 12px, 큰 버튼 14–16px, 카드 묶음 18px, 대화상자 24px, 메뉴 12px, 메뉴 줄 8px, 알약 999px.
- **그림자**: 떠 있는 것만(조작 바, 메뉴, + 버튼). 카드는 그림자 대신 바탕색 차이.
- **간격**: 4px 단위. 화면 좌우 여백 16–24px, 묶음 사이 16px, 줄 높이 54px(폰)·34–40px(PC 메뉴).

## 글꼴

- 본문: **Pretendard** → `'Pretendard', 'Noto Sans KR', system-ui, 'Segoe UI', sans-serif`
  `<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css" />`
- 일본어 문단: Pretendard JP, 중국어 문단: Noto Sans SC (`lang` 속성으로 갈아 끼움 — tokens.css 참고).
- 로고(워드마크): **Nunito 900**, 소문자, 끝에 보라 마침표. 예) `airtalk.` 다른 앱은 앱 이름을 같은 방식으로(예: `deskly.`).
- 크기: 화면 제목 22/800, 섹션 제목 18/800, 줄 제목 16/700(폰)·13.5–14/600–700(PC), 본문 14–15, 보조 12–13, 글자 사이 제목만 `-0.015em ~ -0.02em`.
- 숫자 열은 `font-variant-numeric: tabular-nums`.

## 아이콘

- **Lucide**(`lucide-react` 등), 선 굵기 **1.75**, 둥근 끝. 크기 20–24px(바), 17–18px(메뉴 안).
- 아이콘만 있는 버튼은 배경 없이, 켜짐일 때만 옅은 보라 바탕 + 보라 아이콘.
- 꺼짐 상태는 같은 아이콘 위에 사선 한 줄.

## 화면 구성 원칙

- **폰**: 위 띠(제목 + 오른쪽 아이콘 2–3개), 떠 있는 회색 조작 바(아래), 설정은 아래에서 올라오는 시트, 목록 줄은 흰 카드 묶음(`Group`) + 줄(`OptionRow`).
- **PC 웹**: 폰 배치를 그대로 옮기지 않는다. 옵션 종류와 버튼 모양만 같게 하고 배치는 웹식으로.
  - 위 띠: 로고(왼쪽) / 이름 메뉴(오른쪽, 아바타 + 이름 + ⌄).
  - 주 행동은 떠 있는 + 대신 위쪽 줄의 보라 버튼.
  - 설정은 가운데 창(왼쪽 분류 + 오른쪽 '이름·설명 | 조절').
  - 작업 화면 조작은 디스코드식 아래 묶음 바: `[아이콘 ⌄] [아이콘 ⌄] [항상 보이는 값 칸] [⋯] [주 행동 버튼]`. ⌄ 는 버튼 바로 위 작은 메뉴, 메뉴 줄에 마우스를 올리면 옆으로 선택 목록.
  - 시트(아래에서 올라오는 창)는 PC 에선 가운데 창으로.
- 첫 사용 안내 카드·장황한 설명 넣지 않는다. 빈 화면엔 한 줄 안내만.
- 위험한 동작(삭제)은 작업 화면 안이 아니라 목록에서. 확인 창에 데이터 손실을 명시.

## 다크 모드

모든 색을 토큰으로만 쓰고 다크 값을 함께 정의한다. 단순 반전 금지 — 표의 다크 값을 그대로 쓴다. 테마 선택지는 라이트/다크/시스템.

## 하지 말 것

- 보라를 장식(테두리 남발·그라데이션 배경)에 쓰기.
- 회색 대신 순수 `#808080` 계열, 순수 검정 `#000` 본문.
- 카드마다 그림자, 모서리 4px 이하의 각진 버튼, 알약 모양 주 버튼(주 버튼은 둥근 네모).
- 이모지 아이콘, 영문 대문자 버튼(`textTransform: none`).
- 개발·운영 설명을 일반 화면에 쓰기(copy-rules.md).

## 참고 파일

- `references/tokens.css` — CSS 변수(라이트·다크·글꼴·모서리·그림자). 프레임워크 무관.
- `references/mui-theme.js` — MUI v6+ `createTheme` 그대로 쓰는 테마.
- `references/components.md` — 부품 규격: 버튼, 조작 바, 작은 메뉴·옆 목록, 설정 줄·묶음, 확인 창, 시트, 목록 줄, 언어 칸, 말풍선, 슬라이더.
- `references/copy-rules.md` — 한국어 화면 문구 규칙(말투·오류·확인 창·용어).
- 원본 코드(이 저장소): `client/src/` — `shared/theme.js`, `shared/brand.js`, `phone/common.jsx`, `pc/PcSession.jsx`, `pc/SettingsDialog.jsx`.
